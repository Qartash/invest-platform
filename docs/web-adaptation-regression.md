# Шаг 6 — регрессия: отчёт

Прогон по чистой сборке метро (перезапуск сервера, не HMR). Замер — скриптом
`probe`: горизонтальное переполнение страницы, элементы за краем вьюпорта,
обрезанный текст. На каждой ширине страница перезагружалась (ресайз без
перезагрузки на этом стенде не пересчитывает раскладку — см.
[web-adaptation-baseline.md](web-adaptation-baseline.md)).

## Регрессий адаптации НЕ найдено

Горизонтального переполнения страницы (`scrollWidth > innerWidth`) нет ни на
одной из проверенных ширин ни в одной теме.

## Найденные расхождения — оба BASELINE (были до адаптации)

### B1. Портфель, 375: обрезаны длинные строки сводки
- Экран: [PortfolioScreen.tsx](../mobile/src/screens/investor/PortfolioScreen.tsx)
- «Всего вложено 74 515,64 …» — cw 166 / sw 228; «Полученные дивиденды +4 738» —
  cw 128 / sw 175.
- **Не регрессия.** `git diff` по `summaryRow/summaryLabel/summaryValue/summaryCard`
  пуст — эти стили не менялись. Добавлен только `listWide`, который при
  `isCompact` не применяется. Дефект существовал в базовом коммите.

### B2. Мастер создания проекта, 375: рейл шагов обрезан
- Экран: [CreateProjectScreen.tsx](../mobile/src/screens/founder/CreateProjectScreen.tsx)
- Полоса шагов: контент 660px в контейнере 326px с `overflow-x: hidden` без
  скролла — шаги 5–7 недостижимы жестом.
- **Не регрессия.** Единственное изменение рендера — обёртка `StepRail` в
  `PageContainer`, который на 375 (`isCompact`) возвращает фрагмент без DOM-узла.
  Сам `StepRail` и его контейнер не тронуты. На 1280 рейл помещается целиком.

Обе находки стоит однажды починить, но это отдельная работа вне адаптации под
веб — они одинаково проявляются в нативном приложении.

## Не проверено вживую (нужен аккаунт основателя / данные)

- Сетка «Владею» в 2 колонки (MyProjects) — у admin нет своих проектов.
- Сетки «Разморозки» и «Споры» — на сиде пусто.
- Переключение sheet↔центр у ActionSheet и ProjectHistoryModal — триггерятся
  только с карточек своих проектов.
- Клавиатурный focus-ring живьём — CSS-классы сгенерированы и привязаны к
  состоянию `focused`, но реальный Tab через CDP-стенд не воспроизводится.
- RichTextEditor (tentap поверх WebView) — по плану отдельная проверка.

## Артефакт стенда (не дефект)

В консоли висит `ReferenceError: Modal is not defined` для `AvatarPickerModal` и
`DatePickerModal` — устаревшие lazy-бандлы метро (dev-бандлы без хеша браузер
кэширует по URL, рестарт сервера URL не меняет). Исходники чисты: grep по
`Modal` в обоих файлах пуст, `tsc` проходит, оба диалога открываются и работают.
Уйдёт после сброса кэша браузера.

## Параллельная работа

Фоновая сессия правит внутренние `<Modal>` в `ProjectFinancePanel` и
`ProjectWorksPanel` (задача про миграцию на `Dialog`). Экраны founder-финансов и
работ в этом прогоне отдельно не гонялись, чтобы не пересечься с её изменениями.
